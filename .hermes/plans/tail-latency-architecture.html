Tail Latency & Outlier Detection Test

Многопоточный нагрузочный тест: распределение задержек STT + LLM, детекция выбросов

Нагрузка

  • • 4–16 параллельных воркеров
  • • 10–50 итераций на воркер
  • • Один WAV на итерацию
  • • WAV: 3s речи (Edge TTS / tone)

Метрики (per-stage)

  • • T_connect: POST + WS dial
  • • T_interim: первый interim
  • • T_final: EndOfTurn transcript
  • • T_trans: translation latency
  • • T_llm: GenerateAnswers
  • • T_total: полный цикл

Outlier Detection

  • • IQR: Q1−1.5·IQR / Q3+1.5·IQR
  • • Z-score: >3σ от среднего
  • • SLA breach: >2× порог = warn
  • • SLA breach: >5× порог = critical

Отчёт

  • • stdout: p50/p95/p99/min/max
  • • latency_report.csv: все замеры
  • • outliers.json: выбросы + контекст
  • • exit code 1 если есть критические
