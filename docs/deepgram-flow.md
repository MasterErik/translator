# Потоковая схема STT Deepgram Flux v2

**Статус:** ✅ потоковый  
**Протокол:** WebSocket `wss://api.deepgram.com/v2/listen`  
**Модель:** `flux-general-en`  
**Параметры:** `encoding=linear16&sample_rate=16000&eot_threshold=0.8`

## Типы событий Deepgram Flux

| Событие | STTEvent.Event | Действие |
|---------|---------------|----------|
| `Update` | `"Update"` | Interim → UI (оригинал) + асинхронный перевод (отмена предыдущего) |
| `StartOfTurn` | — | Игнорируется (нет текста) |
| `EndOfTurn` | `"EndOfTurn"` | Final → блокирующая отправка в textStream → запуск перевода |
| `EagerEndOfTurn` | `"EagerEndOfTurn"` | Interim (ранний финал), фильтруется если дублирует EndOfTurn |
| `TurnResumed` | — | Игнорируется (нет текста) |

## Характеристики

| Параметр | Значение |
|----------|----------|
| Аудио-фрейм | 80ms = 1280 сэмплов × 2 байта = 2560 байт |
| Буфер audioCh | 64 фрейма (~5 сек) |
| Буфер textCh | 32 события |
| Задержка STT | < 500ms от речи до текста |
| Реконнект | Exponential backoff: 200ms → 400ms → ... → 30s, до 10 попыток |
| Idle timeout | Herpes-keepalive НЕ поддерживается Flux v2 (вызывает 1006) |

## Ключевые горутины

| Горутина | Роль |
|----------|------|
| `writePump` | audioCh → WebSocket (отправка PCM) |
| `readPump` | WebSocket → parseAndEmit → textCh (получение транскрипций) |
| `routeSTTEvent` (в runSTT) | textCh → textStream с разделением interim/final |
